# Actividad Semana 5
Implementación de la App Llanquihue Tour v3.

## Integrantes
* Jorge Botarro Westerhout

## Estructura
* Model
  - Clases
    - Trabajador: Clase base de todas las demás
    - Guia: Guia Turistico Local
    - Operador: Operador Turistico
    - Transportista: Transportista Turistico
  - Enumeraciones (especialidades de cada tipo de trabajador)
    - TipoGuia
    - TipoTransportista
    - EspecialidadOperador
* Util
  - Filtros: Operaciones en listas de trabajadores para filtrado
  - LectorArchivos: Lectura de listas de trabajadores en archivos de texto estilo csv
* App
  - Main: Punto de entrada de la App

## Instrucciones de uso
Este proyecto fue realizado en IntelliJ IDEA, pero puede ser ejecutado en cualquier IDE de Java.
basta con abrir la carpeta base en el IDE y ejecutar la clase Main.java
